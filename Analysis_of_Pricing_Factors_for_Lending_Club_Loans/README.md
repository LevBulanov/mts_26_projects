# Analysis of Pricing Factors for Lending Club Loans

## Описание проекта

Проект посвящён исследовательскому анализу данных о P2P-кредитах американской платформы **Lending Club** и построению регрессионной модели для изучения факторов, связанных с процентной ставкой по кредиту.

В работе исследуются распределения характеристик кредитов и заёмщиков, проверяются статистические гипотезы, выполняется подготовка признаков и сравниваются линейные модели. Итоговая модель — **OLS-регрессия с робастными стандартными ошибками HC3**.

Датасет: [Lending Club Loan Data (Kaggle)](https://www.kaggle.com/datasets/adarshsng/lending-club-loan-data-csv). Версия данных обновлена, поэтому часть названий столбцов может не совпадать с описанием датасета.

## Цель

Изучить, какие характеристики кредита и заёмщика связаны с процентной ставкой, и оценить объясняющую способность линейной регрессионной модели.

**Целевая переменная:** `int_rate` — процентная ставка по кредиту.

## Основные этапы

1. **Загрузка данных** из `datasets/loan.csv`.
2. **Подготовка данных и Feature Engineering:**
   - преобразование типов и уменьшение потребления памяти;
   - обработка дат и отдельных числовых полей;
   - создание признаков кредитной истории, отношения суммы кредита к доходу, утилизации кредитных линий и других показателей;
   - формирование макрогрупп целей кредита;
   - удаление идентификаторов, текстовых полей, признаков с утечкой целевой переменной и информации, появляющейся после выдачи кредита.
3. **Исследовательский анализ данных (EDA):**
   - распределения сумм кредитов, ставок, доходов и кредитных скоров;
   - сравнение групп по целям кредита и срокам;
   - анализ дефолтов.
4. **Проверка статистических гипотез** о различиях между группами и связи характеристик кредита с его ставкой.
5. **Подготовка признаков к моделированию:**
   - обработка пропусков;
   - кодирование категориальных признаков;
   - стандартизация числовых признаков;
   - анализ мультиколлинеарности, в том числе с помощью VIF.
6. **Обучение и сравнение моделей:** DummyRegressor, линейная регрессия, Lasso, Elastic Net и Ridge с отбором признаков через RFE.
7. **Диагностика итоговой OLS-модели:** проверка гетероскедастичности, линейности, автокорреляции и распределения остатков; использование робастных стандартных ошибок HC3.
8. **Интерпретация коэффициентов** и формулирование выводов.

## Основные результаты

- **R² = 0.440**: модель объясняет около 44% вариации процентной ставки.
- **Adjusted R² = 0.440**.
- Для итоговой модели использованы **робастные стандартные ошибки HC3**, поскольку тест и график остатков указывают на гетероскедастичность.
- В итоговой спецификации не используются `grade` и `sub_grade`: это прямые детерминанты ставки, и их исключение позволяет изучать связь ставки с характеристиками заёмщика до присвоения грейда.
- Среди заметных факторов в отчёте выделены утилизация кредитных линий, отношение суммы кредита к доходу, срок кредита, недавние запросы в кредитное бюро, длительность кредитной истории и показатели недавней кредитной активности.

Коэффициенты следует интерпретировать как **условные статистические связи, а не причинные эффекты**, возможна эндогенность. В ноутбуке отдельно отмечен риск эндогенности. Значения метрик и коэффициентов могут слегка измениться при повторном запуске на другой версии данных или в другом окружении.

## Установка и запуск

### 1. Клонируйте или скачайте проект

```bash
git clone https://github.com/LevBulanov/mts_26_projects.git
cd mts_26_projects/Analysis_of_Pricing_Factors_for_Lending_Club_Loans
```
и подготовьте датасет `datasets/loan.csv`.

### 2. Создайте виртуальное окружение (необязательно, но рекомендуется)

```bash
python -m venv .venv
```

Активируйте окружение:

**Linux / macOS**
```bash
source .venv/bin/activate
```

**Windows**
```bash
.venv\Scripts\activate
```

### 3. Установите зависимости

```bash
pip install pandas numpy matplotlib seaborn plotly scipy statsmodels scikit-learn phik jupyter
```

### 4. Запустите Jupyter Notebook

```bash
jupyter notebook
```

Откройте `analysis_of_pricing_factors_for_lending_club_loans.ipynb` и выполняйте ячейки последовательно сверху вниз.

> Для интерактивных графиков Plotly в ноутбуке задан рендерер `notebook_connected`. Если графики не отображаются в вашей среде, настройте подходящий для неё рендерер Plotly.

## Ограничения

- Для запуска требуется исходный файл `datasets/loan.csv`;
- Результаты описывают статистические зависимости и не доказывают причинно-следственные отношения.
- Гетероскедастичность учитывается робастными стандартными ошибками HC3, но потенциальная эндогенность и пропущенные переменные остаются ограничениями модели.
